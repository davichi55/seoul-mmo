# 서울의 수수께끼 존재 · The Mysterious Creature of Seoul

A Korean-vocabulary MMORPG for the Sogang Korean 5A / 5B courses. Play: https://davichi55.github.io/seoul-mmo/

This repository is the built site; the source lives with the course materials. Characters: KayKit Adventurers (CC0); the Dreamcatcher-named women are Quaternius Ultimate Modular Women (CC0). Music: CC0 from OpenGameArt (assets/music/CREDITS.txt). Sound effects: Kenney Impact Sounds, Sci-Fi Sounds and RPG Audio (CC0).
